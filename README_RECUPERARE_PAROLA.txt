AUTOPIESE - RECUPERARE PAROLA

Aceasta este versiunea actualizata pentru recuperarea parolei.

In Render -> Environment:
RESEND_API_KEY = cheia ta Resend (nu o distribui)
RESEND_FROM = AutoPiese <noreply@passatinterlagos.com>
APP_URL = https://passatinterlagos.com

Domeniul passatinterlagos.com trebuie verificat in Resend pentru trimiterea catre utilizatori reali.

Flux:
Ai uitat parola -> email -> link de resetare -> parola noua.
Tokenul este valabil 30 de minute si o singura folosire.

Nu modifica RESEND_API_KEY si nu o include in fisierele publice.
